# Python Extensions

> Browse extensions that run within the LNbits Python application.

Python extensions add API endpoints, database tables, and frontend templates. They can integrate closely with LNbits and use its existing Python dependencies.

## Installation and trust

Install from your instance's **Extensions** screen, then enable the extension for your account. Follow [Using Extensions](/guide/using-extensions) for the shared steps.

Python extensions execute within the application and do not use the WASM sandbox. Choose sources you trust, check compatibility, and keep extensions up to date. Administrators control which manifests and extensions are available.
