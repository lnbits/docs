## Overview

Create customizable Lightning funding goals with live progress This extension uses the core WASM runtime, with an isolated frontend and permissioned host calls.

## Compatibility

The registry release **0.5.2** requires LNbits **1.6.0** or newer. Use a compatible release from your instance's WASM marketplace. The development guides target LNbits 1.6.2.

## Setup

1. Find **Zap Goals!** in your instance's **Extensions** screen.
2. Check the release requirements and requested permissions, then install it.
3. Enable the extension for your account and open it from LNbits.
4. Follow its settings to configure the feature and select a wallet where required.

See the [extension README](https://github.com/bitkarrot/zapgoalswasm) for its specific workflow. For background payments, review the wallet, per-payment maximum, and destination policy before approval.
